# WASTESENSE Data

This directory contains datasets used by WASTESENSE.

## Dataset Sources

- Google ClusterData 2019
- Google PowerData 2019
- Alibaba ClusterData 2018

## Directory Structure

- `raw/` — Original downloaded datasets
- `interim/` — Intermediate processed data
- `processed/training/` — Training data
- `processed/validation/` — Validation data
- `processed/testing/` — Testing data
- `samples/` — Small demo datasets

## Important

Large datasets must NOT be committed to Git.

Only small sample/demo datasets may be stored in this repository.

Dataset credentials, private files, and sensitive information must never be committed.
